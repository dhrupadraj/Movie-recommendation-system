# 🎬 Movie Recommendation System

A simple yet powerful **Movie Recommendation System** built using **Python, Pandas, NumPy, Seaborn, and Matplotlib**.  
This system analyzes user ratings to recommend similar movies using **correlation-based collaborative filtering**.

---

## 🚀 Features

- 📊 Reads and processes movie rating datasets (`dataset.csv`, `movieIdTitles.csv`)
- 🔍 Calculates average movie ratings and number of ratings
- 🤝 Uses **Pearson correlation** to find movies similar to the one selected
- 🎥 Generates top 4 movie recommendations per movie
- 💾 Exports recommendation data to `MovieRecommendations.csv`
- 🧠 Interactive input for quick recommendations via IPython widgets

---
